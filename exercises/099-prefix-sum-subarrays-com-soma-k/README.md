# #099 - Prefix Sum: Subarrays com Soma == K

Dado nums (com negativos) e k, retorne quantos subarrays somam k.

**Assinatura:** `function subarraySum(nums,k) {}`

**Restrições:** n<=2e5

**Exemplos:**

```txt
subarraySum([1,1,1],2)->2
subarraySum([1,2,3],3)->2
```

**Tags:** prefix-sum, hashmap

**Dica:** Freq de prefix sums.

**Bônus:** Implemente uma versao iterativa (sem recursao).
