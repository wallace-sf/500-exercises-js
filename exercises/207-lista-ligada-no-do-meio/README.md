# #207 - Lista Ligada: Nó do Meio

Retorne o nó do meio (se dois, retorne o segundo).

**Assinatura:** `function middleNode(head) {}`

**Restrições:** n<=2e5

**Exemplo:** `1->2->3->4->5->6 -> 4`

**Tags:** linked-list, two-pointers

**Dica:** Fast anda 2x.

**Bônus:** Nao use loops aninhados (tente O(n) ou O(n log n)).
