# #017 - Recursion: Fast Power

Implement a recursive function that returns x raised to the power n. Do not use Math.pow or the ** operator. Define power(x, 0) = 1 for any x.

**Signature:** `function power(x, n) {}`

**Constraints:** -100 <= x <= 100; n is an integer, -10^9 <= n <= 10^9; if n < 0 then x != 0

**Examples:**

```txt
power(2, 10)->1024
power(2, -2)->0.25
```

**Tags:** recursion, math, divide and conquer

**Hint:** Halve the exponent at each step.

**Bonus:** Write an iterative version that uses O(1) extra memory.
