# #047 - Two Pointers: Container With Most Water

**Signature:** `function maxArea(height) {}`

**Constraints:** n<=2e5

**Tags:** two-pointers, array, greedy

**Hint:** Move the pointer at the shorter height.

**Bonus:** Don't use nested loops (aim for O(n) or O(n log n)).
