# #012 - Recursao: Soma de 1..n

Implemente uma funcao recursiva que retorne a soma de 1 ate n (n>=0).

**Assinatura:** `function sumToN(n) {}`

**Restrições:** 0 <= n <= 1e6

**Exemplos:**

```txt
sumToN(0)->0
sumToN(5)->15
```

**Tags:** recursao

**Dica:** sumToN(n)=n+sumToN(n-1).

**Bônus:** Evite alocar um segundo array do mesmo tamanho (tente in-place).
