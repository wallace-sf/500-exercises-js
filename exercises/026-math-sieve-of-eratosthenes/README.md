# #026 - Math: Sieve of Eratosthenes

Return, in ascending order, all prime numbers less than or equal to n, using the Sieve of Eratosthenes.

**Signature:** `function primesUpTo(n) {}`

**Constraints:** 0 <= n <= 10^6

**Examples:**

```txt
primesUpTo(10)->[2, 3, 5, 7]
primesUpTo(1)->[]
```

**Tags:** math, primes

**Hint:** Instead of testing each number, cross out the multiples of each prime you find.

**Bonus:** Explain why it is enough to start crossing out the multiples of p at p * p.
