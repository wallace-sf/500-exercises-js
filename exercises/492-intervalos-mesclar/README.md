# #492 - Intervalos: Mesclar

Mescle intervalos sobrepostos e retorne ordenado.

**Assinatura:** `function mergeIntervals(intervals) {}`

**Restrições:** n<=2e5

**Exemplo:** `mergeIntervals([[1,3],[2,6],[8,10],[15,18]])->[[1,6],[8,10],[15,18]]`

**Tags:** intervals

**Dica:** Sort + sweep.

**Bônus:** Trate entradas vazias e valores negativos corretamente.
