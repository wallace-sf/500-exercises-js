# #174 - Pilha: Parenteses Validos

Verifique se parenteses estao balanceados.

**Assinatura:** `function isValidBrackets(s) {}`

**Restrições:** |s|<=2e5

**Exemplos:**

```txt
isValidBrackets('([])')->true
isValidBrackets('([)]')->false
```

**Tags:** stack

**Dica:** Pilha de aberturas.

**Bônus:** Nao use loops aninhados (tente O(n) ou O(n log n)).
