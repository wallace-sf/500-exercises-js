# #489 - Intervals: Merge

**Signature:** `function mergeIntervals(intervals) {}`

**Constraints:** n<=2e5

**Example:** `mergeIntervals([[1,3],[2,6],[8,10],[15,18]])->[[1,6],[8,10],[15,18]]`

**Tags:** intervals
