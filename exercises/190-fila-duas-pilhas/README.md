# #190 - Fila: Duas Pilhas

**Assinatura:** `class MyQueue { push(x){} pop(){} peek(){} empty(){} }`

**Restrições:** ops<=2e5

**Tags:** queue, stack

**Dica:** Transfira quando out estiver vazia.

**Bônus:** Nao use loops aninhados (tente O(n) ou O(n log n)).
