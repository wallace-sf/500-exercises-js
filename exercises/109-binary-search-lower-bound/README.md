# #109 - Binary Search: Lower Bound

Return the smallest i with nums[i]>=x (or n).

**Signature:** `function lowerBound(nums,x) {}`

**Constraints:** n<=2e5

**Examples:**

```txt
lowerBound([1,3,3,7],3)->1
lowerBound([1,3,3,7],9)->4
```

**Tags:** binary-search

**Hint:** Binary search over [lo, hi).

**Bonus:** Don't use nested loops (aim for O(n) or O(n log n)).
