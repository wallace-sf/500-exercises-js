# #015 - Recursion: Reverse an Integer

Implement a recursive function that returns the number formed by the digits of n in reverse order. Leading zeros of the result are dropped. Do not convert n to a string.

**Signature:** `function reverseNumber(n) {}`

**Constraints:** 0 <= n <= 10^15

**Examples:**

```txt
reverseNumber(1230)->321
reverseNumber(0)->0
```

**Tags:** recursion, math

**Hint:** You may need to carry the part already reversed from one call to the next.

**Bonus:** Solve it without any extra parameter (no accumulator).
