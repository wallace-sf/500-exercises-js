# #028 - Math: Integer Square Root

Return the largest integer r such that r * r <= n. Do not use Math.sqrt, Math.pow or the ** operator.

**Signature:** `function isqrt(n) {}`

**Constraints:** 0 <= n <= 10^15

**Examples:**

```txt
isqrt(16)->4
isqrt(15)->3
```

**Tags:** math, binary search

**Hint:** The answer is somewhere between 0 and n. How can you find it without trying every value?

**Bonus:** Implement it with Newton's method and compare the number of iterations.
