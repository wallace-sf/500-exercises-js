# #029 - Math: GCD

Implement gcd(a,b) using the Euclidean algorithm.

**Signature:** `function gcd(a,b) {}`

**Constraints:** 0<=a,b<=1e18

**Examples:**

```txt
gcd(54,24)->6
gcd(0,7)->7
```

**Tags:** math

**Hint:** gcd(a,b)=gcd(b,a%b).

**Bonus:** Don't use nested loops (aim for O(n) or O(n log n)).
