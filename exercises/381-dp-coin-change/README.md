# #381 - DP: Coin Change

Minimo numero de moedas para amount, ou -1.

**Assinatura:** `function coinChange(coins,amount) {}`

**Restrições:** amount<=1e4

**Exemplos:**

```txt
coinChange([1,2,5],11)->3
coinChange([2],3)->-1
```

**Tags:** dp

**Dica:** dp[a]=min(dp[a-c]+1).

**Bônus:** Nao use loops aninhados (tente O(n) ou O(n log n)).
