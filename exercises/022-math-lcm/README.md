# #022 - Math: LCM

Implement lcm(a,b) using gcd(a,b) (exercise #021). The result is always non-negative. If a==0 or b==0, return 0.

**Signature:** `function lcm(a,b) {}`

**Constraints:** |a|,|b| <= 10^6

**Examples:**

```txt
lcm(6,8)->24
lcm(0,7)->0
```

**Tags:** math

**Hint:** lcm=|a/gcd(a,b)*b|.

**Bonus:** Compute the LCM of an array of numbers.
