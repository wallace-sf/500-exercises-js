# #027 - Math: LCM

Implement lcm(a,b) using gcd(a,b). If a==0 or b==0, return 0.

**Signature:** `function lcm(a,b) {}`

**Constraints:** |a|,|b|<=1e18

**Examples:**

```txt
lcm(6,8)->24
lcm(0,7)->0
```

**Tags:** math

**Hint:** lcm=|a/gcd(a,b)*b|.
