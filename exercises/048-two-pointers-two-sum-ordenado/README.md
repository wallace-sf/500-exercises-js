# #048 - Two Pointers: Two Sum (ordenado)

Dado nums ORDENADO e target, retorne indices de um par que soma target ou [-1,-1].

**Assinatura:** `function twoSumSorted(nums,target) {}`

**Restrições:** n<=2e5

**Exemplo:** `twoSumSorted([1, 2, 5, 6, 7, 7, 11, 12],5)->(indices)`

**Tags:** two-pointers, array

**Dica:** i/j e ajuste pela soma.

**Bônus:** Evite alocar um segundo array do mesmo tamanho (tente in-place).
