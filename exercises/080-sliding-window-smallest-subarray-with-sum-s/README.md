# #080 - Sliding Window: Smallest Subarray With Sum >= S

Given positive nums and S, return the length of the smallest subarray with sum >= S (0 if none exists).

**Signature:** `function minSubArrayLen(S,nums) {}`

**Constraints:** n<=2e5

**Example:** `minSubArrayLen(7,[2,3,1,2,4,3])->2`

**Tags:** sliding-window, array

**Hint:** Add and shrink while sum >= S.

**Bonus:** Don't use nested loops (aim for O(n) or O(n log n)).
