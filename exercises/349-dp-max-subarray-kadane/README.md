# #349 - DP: Max Subarray (Kadane)

**Signature:** `function maxSubArray(nums) {}`

**Constraints:** n<=2e5

**Example:** `maxSubArray([-2,1,-3,4,-1,2,1,-5,4])->6`

**Tags:** dp

**Hint:** cur=max(x,cur+x).

**Bonus:** Don't use nested loops (aim for O(n) or O(n log n)).
