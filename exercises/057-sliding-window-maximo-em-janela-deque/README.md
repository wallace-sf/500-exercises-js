# #057 - Sliding Window: Maximo em Janela (deque)

Retorne o maximo de cada janela de tamanho k.

**Assinatura:** `function maxSlidingWindow(nums,k) {}`

**Restrições:** n<=2e5

**Exemplo:** `maxSlidingWindow([1,3,-1,-3,5,3,6,7],3)->[3,3,5,5,6,7]`

**Tags:** sliding-window, deque

**Dica:** Deque monotônica de indices.

**Bônus:** Evite alocar um segundo array do mesmo tamanho (tente in-place).
