# #014 - Recursion: Palindrome Check

Implement a recursive function that returns true if the string s reads the same forwards and backwards. The comparison is exact (case-sensitive, every character counts).

**Signature:** `function isPalindrome(s) {}`

**Constraints:** 0 <= s.length <= 1000

**Examples:**

```txt
isPalindrome('racecar')->true
isPalindrome('abca')->false
```

**Tags:** recursion, strings

**Hint:** Compare the two ends of the string, then solve the same problem for what is left in between.

**Bonus:** Ignore case and non-alphanumeric characters, so that "A man, a plan, a canal: Panama" is a palindrome.
