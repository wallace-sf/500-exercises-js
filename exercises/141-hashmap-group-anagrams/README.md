# #141 - HashMap: Group Anagrams

Group the strings by anagram and return the groups.

**Signature:** `function groupAnagrams(words) {}`

**Constraints:** total chars<=2e5

**Example:** `groupAnagrams(['eat','tea','tan','ate','nat','bat']) -> groups`

**Tags:** hashmap, string

**Hint:** The key can be the sorted letters.

**Bonus:** Don't use nested loops (aim for O(n) or O(n log n)).
