# #013 - Recursao: Soma de Digitos

Implemente uma funcao recursiva que retorne a soma dos digitos de um inteiro nao-negativo.

**Assinatura:** `function sumDigits(n) {}`

**Restrições:** 0 <= n <= 10^15

**Exemplos:**

```txt
sumDigits(4029)->15
sumDigits(0)->0
```

**Tags:** recursao, math

**Dica:** Use n%10 e Math.floor(n/10).

**Bônus:** Implemente uma versao iterativa (sem recursao).
