# #166 - Queue: Two Stacks

Implement a queue using two stacks.

**Signature:** `class MyQueue { push(x){} pop(){} peek(){} empty(){} }`

**Constraints:** ops<=2e5

**Example:** `push(1),push(2),peek()->1,pop()->1,empty()->false`

**Tags:** queue, stack

**Hint:** Transfer when the out-stack is empty.

**Bonus:** Don't use nested loops (aim for O(n) or O(n log n)).
