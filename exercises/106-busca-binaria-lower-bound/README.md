# #106 - Busca Binaria: Lower Bound

Retorne menor i com nums[i]>=x (ou n).

**Assinatura:** `function lowerBound(nums,x) {}`

**Restrições:** n<=2e5

**Exemplos:**

```txt
lowerBound([1,3,3,7],3)->1
lowerBound([1,3,3,7],9)->4
```

**Tags:** binary-search

**Dica:** Busca em [lo,hi).

**Bônus:** Otimize para memoria (O(1) extra quando possivel).
