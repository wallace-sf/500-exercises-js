# #160 - HashMap: Primeiro Caractere Unico

Retorne o indice do primeiro char que aparece uma vez; -1 se nao existir.

**Assinatura:** `function firstUniqChar(s) {}`

**Restrições:** |s|<=2e5

**Exemplos:**

```txt
firstUniqChar('leetcode')->0
firstUniqChar('aabb')->-1
```

**Tags:** hashmap, string

**Dica:** Conte e depois varra.

**Bônus:** Trate entradas vazias e valores negativos corretamente.
