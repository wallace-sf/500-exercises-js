# #030 - Math: Modular Exponentiation

Return (a^b) mod m. All values are BigInt. Do not use the ** operator. Remember that any value mod 1 is 0.

**Signature:** `function modPow(a, b, m) {}`

**Constraints:** 0 <= a, b <= 10^18; 1 <= m <= 10^18 (all BigInt)

**Examples:**

```txt
modPow(2n, 10n, 1000n)->24n
modPow(3n, 0n, 7n)->1n
```

**Tags:** math, divide and conquer, bigint

**Hint:** Same idea as #017, keeping every intermediate value small.

**Bonus:** Use modPow and Fermat's little theorem to compute the modular inverse of a modulo a prime p.
