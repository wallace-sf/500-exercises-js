# #022 - Math: Fracao Irredutivel

Dado p e q (!=0), retorne [p',q'] reduzida por gcd e com q'>0.

**Assinatura:** `function reduceFraction(p,q) {}`

**Restrições:** |p|,|q|<=1e18

**Exemplos:**

```txt
reduceFraction(8,12)->[2,3]
reduceFraction(-6,9)->[-2,3]
```

**Tags:** math

**Dica:** Divida por gcd e normalize sinal do denominador.

**Bônus:** Evite alocar um segundo array do mesmo tamanho (tente in-place).
