# #023 - Math: Irreducible Fraction

Given p and q (!=0), return [p',q'] reduced by the gcd and with q'>0. Zero is represented as [0,1].

**Signature:** `function reduceFraction(p,q) {}`

**Constraints:** |p|,|q| <= 10^15; q != 0

**Examples:**

```txt
reduceFraction(8,12)->[2,3]
reduceFraction(-6,9)->[-2,3]
```

**Tags:** math

**Hint:** Divide by the gcd and normalize the denominator's sign.

**Bonus:** Implement addFractions(p1, q1, p2, q2), returning the sum as an irreducible fraction.
