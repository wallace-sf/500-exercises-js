# #027 - Math: Prime Factorization

Return the prime factorization of n as a list of [prime, exponent] pairs, in ascending order of prime.

**Signature:** `function factorize(n) {}`

**Constraints:** 2 <= n <= 10^12

**Examples:**

```txt
factorize(360)->[[2, 3], [3, 2], [5, 1]]
factorize(13)->[[13, 1]]
```

**Tags:** math, primes

**Hint:** Trial division up to the square root is enough, but pay attention to what is left at the end.

**Bonus:** Use the sieve from #026 to factorize many numbers up to 10^6 quickly.
