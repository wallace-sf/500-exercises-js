# #029 - Math: MDC (GCD)

Implemente gcd(a,b) com Euclides.

**Assinatura:** `function gcd(a,b) {}`

**Restrições:** 0<=a,b<=1e18

**Exemplos:**

```txt
gcd(54,24)->6
gcd(0,7)->7
```

**Tags:** math

**Dica:** gcd(a,b)=gcd(b,a%b).

**Bônus:** Nao use loops aninhados (tente O(n) ou O(n log n)).
