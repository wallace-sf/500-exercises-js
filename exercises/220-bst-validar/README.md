# #220 - BST: Validar

Retorne true se a arvore for uma BST valida.

**Assinatura:** `function isValidBST(root) {}`

**Restrições:** n<=2e5

**Exemplos:**

```txt
isValidBST([2,1,3])->true
isValidBST([5,1,4,null,null,3,6])->false
```

**Tags:** bst, tree

**Dica:** DFS com limites.

**Bônus:** Evite alocar um segundo array do mesmo tamanho (tente in-place).
