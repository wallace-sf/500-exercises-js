# #301 - Backtracking: Permutacoes

Retorne todas as permutacoes de nums (sem repeticoes).

**Assinatura:** `function permute(nums) {}`

**Restrições:** n<=10

**Exemplo:** `permute([1,2,3])->6 permutacoes`

**Tags:** backtracking

**Dica:** Swap in-place.

**Bônus:** Nao use loops aninhados (tente O(n) ou O(n log n)).
