# #025 - Math: Base Conversion

Return the representation of the non-negative integer n in the given base, using the digits 0-9 followed by the lowercase letters a-z. Do not use Number.prototype.toString(base) or parseInt.

**Signature:** `function toBase(n, base) {}`

**Constraints:** 0 <= n <= Number.MAX_SAFE_INTEGER; 2 <= base <= 36

**Examples:**

```txt
toBase(10, 2)->'1010'
toBase(255, 16)->'ff'
```

**Tags:** math, strings

**Hint:** Dividing by the base reveals one digit at a time.

**Bonus:** Implement the inverse: fromBase(str, base).
