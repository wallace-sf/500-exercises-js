# #051 - Two Pointers: Two Sum (ordenado)

**Restrições:** n<=2e5

**Exemplo:** `twoSumSorted([-3, -3, 5, 5, 7, 7, 12, 15],7)->(indices)`

**Tags:** two-pointers, array

**Dica:** i/j e ajuste pela soma.
