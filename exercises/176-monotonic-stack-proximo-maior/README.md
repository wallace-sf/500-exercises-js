# #176 - Monotonic Stack: Proximo Maior

Retorne o proximo maior elemento a direita, ou -1.

**Assinatura:** `function nextGreater(nums) {}`

**Restrições:** n<=2e5

**Exemplo:** `nextGreater([2,1,2,4,3])->[4,2,4,-1,-1]`

**Tags:** stack, monotonic-stack

**Dica:** Pilha decrescente de indices.

**Bônus:** Implemente uma versao iterativa (sem recursao).
