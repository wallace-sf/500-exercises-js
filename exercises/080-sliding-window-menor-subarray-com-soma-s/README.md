# #080 - Sliding Window: Menor Subarray com Soma >= S

Dado nums positivos e S, retorne o tamanho do menor subarray com soma >= S (0 se nao existir).

**Assinatura:** `function minSubArrayLen(S,nums) {}`

**Restrições:** n<=2e5

**Exemplo:** `minSubArrayLen(7,[2,3,1,2,4,3])->2`

**Tags:** sliding-window, array

**Dica:** Some e encolha enquanto soma>=S.

**Bônus:** Nao use loops aninhados (tente O(n) ou O(n log n)).
