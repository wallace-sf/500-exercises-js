# #165 - HashMap: Agrupar Anagramas

Agrupe strings por anagramas e retorne os grupos.

**Assinatura:** `function groupAnagrams(words) {}`

**Restrições:** total chars<=2e5

**Exemplo:** `groupAnagrams(['eat','tea','tan','ate','nat','bat']) -> grupos`

**Tags:** hashmap, string

**Dica:** Chave pode ser letras ordenadas.

**Bônus:** Nao use loops aninhados (tente O(n) ou O(n log n)).
