# #101 - Binary Search: Minimum in Rotated Array

**Signature:** `function findMinRotated(nums) {}`

**Constraints:** n<=2e5

**Example:** `findMinRotated([4,5,6,7,0,1,2])->0`

**Tags:** binary-search

**Hint:** Compare mid with hi.

**Bonus:** Don't use nested loops (aim for O(n) or O(n log n)).
