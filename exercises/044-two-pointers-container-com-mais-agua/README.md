# #044 - Two Pointers: Container com Mais Agua

Dado height, retorne a area maxima de agua contida por duas linhas.

**Assinatura:** `function maxArea(height) {}`

**Restrições:** n<=2e5

**Exemplo:** `maxArea([1, 8, 6, 2, 5, 4, 8, 3, 7])->49`

**Tags:** two-pointers, array, greedy

**Dica:** Movimente o ponteiro da menor altura.

**Bônus:** Otimize para memoria (O(1) extra quando possivel).
