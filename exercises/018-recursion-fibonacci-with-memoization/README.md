# #018 - Recursion: Fibonacci with Memoization

Return the n-th Fibonacci number, where fib(0) = 0, fib(1) = 1 and fib(n) = fib(n - 1) + fib(n - 2). Use recursion with memoization. Note: the tests include n = 78, so a solution that repeats work will never finish.

**Signature:** `function fib(n) {}`

**Constraints:** 0 <= n <= 78 (fib(78) is the largest that fits exactly in a JS number)

**Examples:**

```txt
fib(10)->55
fib(0)->0
```

**Tags:** recursion, memoization

**Hint:** Don't compute the same value twice.

**Bonus:** Write a bottom-up (iterative) version that uses O(1) extra memory.
