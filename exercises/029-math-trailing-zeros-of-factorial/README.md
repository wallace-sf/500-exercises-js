# #029 - Math: Trailing Zeros of Factorial

Return how many zeros n! (n factorial) ends with. Note that n! is far too large to be computed directly.

**Signature:** `function trailingZeros(n) {}`

**Constraints:** 0 <= n <= 10^9

**Examples:**

```txt
trailingZeros(5)->1
trailingZeros(3)->0
```

**Tags:** math

**Hint:** A trailing zero comes from a factor 10 = 2 x 5. Which of the two factors is rarer?

**Bonus:** Find the smallest n such that n! ends with at least k zeros.
